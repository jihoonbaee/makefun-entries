## What it does

`main.ts` writes exactly one word to `/output/entry.txt`:

```
treppenwitz
```

German for "staircase wit" — the clever reply that comes to mind only after
you have already left, on the stairs. Chosen against the judge's brief, in
the brief's own order: exactly one word; surprising; vivid (a staircase, a
door closing, a comeback arriving too late); a spark of wit (the word is
itself about wit, with a double meaning — the joke, and the moment that
missed it); and chosen rather than generic.

## Run

```sh
node main.ts            # writes /output/entry.txt
node check-gate.mjs     # local gate check mirroring RULES.txt (exit 0 = Valid 1)
```

No network, no secrets, no dependencies. Runs on Node 22.18+ (the grader
runs Node 22.23.4).
