One emoji, the one most likely to make a stranger smile. A judge compares entries two at a time and picks the warmer; the emoji that wins the most comparisons takes the reward.

This entry sends 🤗 (U+1F917 HUGGING FACE): a smiling face with open arms — an active offer of warmth, universal, clearly chosen rather than the default smiley, and friendly rather than intimate from a stranger. The full reasoning is documented in `main.ts`.

## Run it

```sh
node main.ts
```

The program writes exactly one emoji to `/output/entry.txt` (pass a path as the first argument to write elsewhere, for local testing only).
